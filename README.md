# Tippo

**Tippo ist ein Schreibtrainer und Schreibtest direkt im Browser.** Übe mit
eigenen oder mitgelieferten Texten, erkenne deine häufigsten Fehler und
verfolge deinen Fortschritt.

[**Tippo öffnen**](Tippo.html)

## Das kannst du damit machen

- Freies Tippen und zeitbegrenzte Schreibtests
- Tempo und Genauigkeit live verfolgen und Ergebnisse vergleichen
- Fehler analysieren, Tasten-Feedback anzeigen und Schwächen gezielt trainieren
- Eigene Texte einfügen oder Textdateien importieren
- Ergebnisse ansehen, drucken oder als TXT und PNG exportieren
- Zwischen hellem und dunklem Design wechseln

## Schnellstart

1. Öffne [Tippo online](https://nenu2000.github.io/Tippo/) oder
   [`Tippo.html`](Tippo.html) in einem aktuellen Browser.
2. Wähle einen Text aus der Seitenleiste oder füge deinen eigenen hinzu.
3. Tippe direkt los oder starte einen Schreibtest, um ein Ergebnis zu speichern.

Du brauchst keine Installation, keinen Build-Schritt und keine externen
Abhängigkeiten.

## Veröffentlichung

Jeder Push auf `main` veröffentlicht Tippo automatisch über GitHub Pages.
Die Startseite wird bei der Veröffentlichung direkt aus `Tippo.html` erzeugt,
damit die App-Datei die einzige Quelle bleibt. Die Veröffentlichung lässt sich
außerdem unter **Actions → Deploy Tippo to GitHub Pages → Run workflow**
manuell starten.

## Daten und Datenschutz

Einstellungen, Texte und Übungsergebnisse werden standardmäßig lokal in deinem
Browser gespeichert. Sie werden nicht an einen Server übertragen. In
unterstützten Browsern kannst du optional einen Ordner verbinden, um Texte und
gespeicherte Testergebnisse dort abzulegen. Der Zugriff auf den Ordner erfolgt
nur mit deiner Freigabe.

## Projektdateien

- `Tippo.html` – vollständige, eigenständige Anwendung (HTML, CSS, JavaScript
