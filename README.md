# Tippo

Schreibtraining für Klasse 7–10 mit Übungen, Tests, Fortschritt und dem Spiel Wortpost. Die Website läuft mit HTML, CSS und JavaScript. Eigene Texte, Testergebnisse und Rekorde bleiben im Browser auf dem jeweiligen Gerät.

Öffne für eine lokale Vorschau `index.html` im Browser.

## Auf GitHub Pages veröffentlichen

1. Lade den Inhalt dieses Ordners in den Hauptordner des GitHub-Repositorys hoch. `index.html`, `404.html`, `.nojekyll` und `assets/` gehören auf dieselbe Ebene.
2. Öffne **Settings → Pages**. Wähle **Deploy from a branch**, den Branch **main** und **/(root)**. Speichere.
3. Öffne die von GitHub angezeigte Pages-Adresse. Der frühere Link `tippoo.html` leitet zur Startseite weiter.

Das Logo kommt aus `assets/logo.svg`. Es lässt sich auf derselben Website mit `<img src="./assets/logo.svg" alt="Tippo">` einbinden.
